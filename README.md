# Lingoduo - сайт для изучения сербского
Проект веб-приложения, целью которого является изучение сербского языка. Посетители могут просматривать список доступных слов,
переводов и соответствующих словам изображений. Для зарегистрированных пользователей доступно также добавление новых слов
(тоже с переводом и при желании картинкой). Помиомо этого зарегистрированные пользователи могут участвовать в квизе знатоков
сербского языка и просматривать результаты участников в общем рейтинге. Приятного обучения!

## Как использовать

1. Скачать этот репозиторий или клонировать его
2. Перейти в папку репозитория при помощи `cd`
3. `pip3 install -r requirements.txt`
4. `python3 manage.py runserver`

## Дополнительные замечания
При тестировании с помощью `pylint` рекомендуется запускать проверку из папки, содержащей проект DjoProject,
применив команду `pylint --load-plugins=pylint_django DjoProject/`. В этом случае `pylint` не будет выдавать ложных ошибок.
(Для этого используется установленный `pylint-django==2.7.0` из `requirements.txt`)
